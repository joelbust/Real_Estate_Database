# Real Estate Database System

A database-driven real estate management application built with PHP, SQL, HTML, and CSS. The project provides a web-based interface for managing real estate data such as properties, clients, agents, and related records.

## Overview

This project was designed to demonstrate relational database design, backend integration, and web-based data management. Users can interact with real estate records through a simple web interface connected to a SQL database.

## Features

- Web interface for viewing and managing real estate data
- SQL database integration
- Property record organization and retrieval
- Structured relational database design
- PHP-based backend logic
- HTML/CSS frontend interface

## Technologies Used

- PHP
- SQL
- HTML
- CSS

## Setup Instructions

1. Clone the repository:

```bash
git clone https://github.com/joelbust/Real_Estate_Database.git
```

2. Move the project folder into your local server directory, such as:

```bash
htdocs/
```

if using XAMPP.

3. Start Apache and MySQL using XAMPP or another local server environment.

4. Import the SQL database file into MySQL/phpMyAdmin.

5. Update any database connection settings if needed.

6. Open the project in your browser through localhost.
